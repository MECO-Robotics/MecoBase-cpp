# Simulation battery

The shared desktop battery helper belongs to MecoSimulation. Start with its [battery overview](https://github.com/MECO-Robotics/MecoSimulation-cpp/blob/wpilib-2026/docs/simulation-basics.md#shared-battery) and [public helper](https://github.com/MECO-Robotics/MecoSimulation-cpp/blob/wpilib-2026/adapters/wpilib-2026/include/meco/sim/BatterySupply.h). The robot application calls it after a shared runtime period.
